Crawler

Drop in a 10-K or 10-Q and click Run. The server reads the filing, extracts the statements, checks the arithmetic and builds a BMG Capital company report in which every figure cites its page. The spider then shows each finding where it sits in the document.

Your file is not saved. While it uploads, a large file may be buffered in a temporary file that is deleted when the upload request ends; the server then reads it in memory. The finished report is kept in memory for up to one hour so you can reopen it or download the PDF, then discarded; a server restart clears it sooner. Nothing is saved to the vault unless the owner presses Save with the owner key.
